# CSM-7 Class Attendance

Installable attendance site for B.Tech First Year, CSM-7. The register currently contains the 103 student entries visible in the supplied screenshots; two rows are still missing, and names clipped in the screenshots are flagged for correction.

Attendance and roster edits are stored in the browser on the device used to enter them. They are not synchronized between devices. Use **Export CSV** to save a dated attendance sheet.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The website is served over HTTPS and can be installed from a compatible browser.
